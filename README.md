## 📋 درباره پروژه
**اُدی مووی** یک وب‌اپلیکیشن سینمایی کامل و واکنش‌گرا هستش که با هدف ارائه اطلاعات فیلم‌ها، سریال‌ها و هنرمندان ساخته شده. این پروژه با تمرکز روی تجربه کاربری روان و دسترسی سریع به محتوای مورد نظر کاربران طراحی شده.

## ✨ ویژگی‌ها و امکانات

### 🎯 قابلیت‌های اصلی
- **جستجوی پیشرفته**: امکان جستجوی همزمان در بین:
  - 🎬 فیلم‌ها
  - 📺 سریال‌ها
  - 🎭 بازیگران
  - ✍️ نویسندگان
  - 🎥 کارگردانان

- **دسته‌بندی‌های متنوع**:
  - 🔥 محبوب‌ها
  - 🆕 آخرین‌ها
  - 📺 در حال پخش
  - ⭐ بیشترین امتیاز
  - ⏳ به زودی
  - 🆓 فیلم‌های رایگان

- **فیلترهای پیشرفته**:
  - تفکیک فیلم و سریال
  - دسته‌بندی بر اساس ژانر (به زودی)
  - فیلتر بر اساس سال تولید (به زودی)

#### فرانت‌اند
- **React 18**: برای ساخت رابط کاربری پویا و کامپوننت‌محور
- **Tailwind CSS**: برای طراحی سریع، واکنش‌گرا و زیبا
- **Swiper.js**: برای ایجاد اسلایدرهای حرفه‌ای و لمسی در بخش‌های مختلف
- **React Hooks**: مدیریت state و اثرات جانبی

#### ارتباط با سرور
- **RESTful API**: ارتباط با سرور و دریافت اطلاعات به صورت استاندارد
- **Axios/Fetch**: برای درخواست‌های HTTP

#### ابزارهای دیگر
- **React Router**: برای ناوبری بین صفحات
- **Context API**: مدیریت state سراسری
- **Local Storage**: ذخیره‌سازی اطلاعات کاربر و علاقه‌مندی‌ها

## 🚀 شروع سریع برای توسعه‌دهندگان

### پیش‌نیازها
- Node.js (نسخه 16 یا بالاتر)
- npm یا yarn

### نصب و راه‌اندازی

```bash
# 1. کلون کردن مخزن
git clone https://github.com/yourusername/odmovie.git
cd odmovie

# 2. نصب وابستگی‌ها
npm install
# یا
yarn install

# 3. تنظیم متغیرهای محیطی
# فایل .env.local ایجاد کنید و کلید API خود را وارد کنید
cp .env.example .env.local
